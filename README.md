# Mohammad Aatif Shaikh
A one-page portfolio of selected AI engineering projects and experience.
Built with React and Create React App, with local Geist fonts and a persistent light/dark theme.
Run `npm start` for development or `npm run build` for the production site.
GitHub Pages serves `build/` at [aatif101.github.io/aatif_website](https://aatif101.github.io/aatif_website/) via `npm run deploy`.
