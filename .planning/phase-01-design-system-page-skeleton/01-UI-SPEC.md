## Design System

| Property | Value | Source |
|----------|-------|--------|
| Tool | none | REQUIREMENTS.md — no component library in scope |
| Preset | not applicable | No shadcn; plain Tailwind CSS 3.3 |
| Component library | none | STACK.md — React 18 + Tailwind CSS 3.3 + CRA |

**Deletions contracted in Phase 1:**
- Remove `tailwind.config.js` `cosmic.*` color tokens (all 7 values)
- Remove `tailwind.config.js` `terminal.*` color tokens (all 3 values)
- Remove `tailwind.config.js` `fontFamily.mono` (JetBrains Mono stack)
- Remove `tailwind.config.js` `animation.pulse-glow` and its `keyframes` block
- Remove `public/index.html` Google Fonts link for JetBrains Mono; replace with Inter 400 + 600

- Nav anchor links: 44px minimum tap target on mobile

## Typography

**Typeface:** Inter (Google Fonts). Loaded weights: 400 (Regular), 600 (SemiBold). No other weights loaded.

| Role | Size | Weight | Line Height | Tailwind Classes | Usage |
|------|------|--------|-------------|-----------------|-------|
| Display | 36px (desktop) / 28px (mobile) | 600 SemiBold | 1.15 | `text-4xl font-semibold leading-tight` / `sm:text-3xl` | Full name "Mohammad Aatif Shaikh" — dominant element |
| Heading | 20px | 600 SemiBold | 1.25 | `text-xl font-semibold leading-snug` | Section headings (Experience, Projects, etc.) — established in shell, used Phase 2+ |
| Body | 16px | 400 Regular | 1.6 | `text-base font-normal leading-relaxed` | Tagline, summary prose, nav links, contact row text |
| Label | 14px | 400 Regular | 1.4 | `text-sm font-normal leading-normal` | Work authorization note, location, secondary metadata |

**Letter spacing:** Default (0) for all roles. No `tracking-*` overrides.

**Font stack in tailwind.config.js:**
```js
fontFamily: {
  sans: ['Inter', 'system-ui', 'sans-serif'],
}
```

**Body element:** `font-sans` applied at the root `<body>` or on `<App>` wrapper. No `font-mono` anywhere after Phase 1 completes.

## Color

| Role | Hex | Tailwind Token | Usage |
|------|-----|----------------|-------|
| Dominant (60%) | `#fafaf8` | `bg-[#fafaf8]` | Page background, all surfaces — applied to `<body>` and `<App>` wrapper |
| Secondary (30%) | `#111111` | `text-[#111]` | All body text, headings, nav links, contact row text |
| Accent (10%) | `#555555` | `text-[#555]` | Contact row separator dots/pipes, location text, work auth note, nav link hover underline |
| Muted | `#999999` | `text-[#999]` | Placeholder text only — not used in Phase 1 UI |

**Accent reserved for:** Contact row separators (between email / LinkedIn / GitHub / location items), work authorization note text, nav anchor link hover state underline. Accent is NOT used for headings, body copy, or CTA labels.

**Destructive:** Not applicable in Phase 1. No destructive actions exist in the header, summary, or nav shell.

**Explicit prohibitions (from REQUIREMENTS.md DS-02, DS-03):**
- No `#0a0a0f`, `#05050a` (cosmic dark backgrounds)
- No `#6366f1`, `#3b82f6`, `#10b981`, `#f59e0b`, `#ec4899` (cosmic accent colors)
- No `#00ff41`, `#ffbf00`, `#ff0040` (terminal colors)
- No `box-shadow` with color values
- No `text-shadow`
- No `opacity` animations or gradient backgrounds

**tailwind.config.js additions:**
```js
colors: {
  surface: '#fafaf8',
  ink: '#111111',
  muted: '#555555',
}
```

## Component Inventory (Phase 1 scope)

### Header.js (full rebuild)

**Structure:**
```
<header>  ← sticky top-0, bg-surface, no border, no shadow
  <div>   ← max-w-3xl mx-auto px-6 py-12 (desktop) / py-8 (mobile)
    <h1>  ← Display: "Mohammad Aatif Shaikh"
    <p>   ← Body: one-liner tagline (text from cv.md)
    <div> ← contact row: horizontal flex, gap-2, flex-wrap on mobile
      <a> email
      <span> · separator (accent color)
      <a> LinkedIn
      <span> · separator
      <a> GitHub
      <span> · separator
      <span> location text
      <span> · separator
      <span> work auth note (Label size)
```

- Sticky behavior: `sticky top-0 z-10` — remains visible while scrolling
- No background blur, no border-bottom, no box-shadow on the sticky header
- Contact links: plain `<a>` elements, no button wrappers, no icon-only presentation (text label preferred; icons from react-icons may accompany text if layout allows but are not required)
- `href` values: `mailto:`, `https://linkedin.com/in/...`, `https://github.com/aatif101`

### Summary prose (in App.js or dedicated SummarySection.js)

**Structure:**
```
<section id="summary">
  <div>  ← max-w-3xl mx-auto px-6 py-0 (no extra top padding — flows directly from header)
    <p>  ← Body: full CV summary paragraph, no truncation
```

- No `<div>` with border, background-color, border-radius, or box-shadow wrapping the paragraph
- No section heading label above summary — prose begins immediately

### Nav (minimal, in App.js or Nav.js)

**Structure:**
```
<nav aria-label="Page sections">
  <ul>  ← horizontal flex, gap-4, centered or right-aligned
    <li><a href="#experience">Experience</a></li>
    <li><a href="#projects">Projects</a></li>
    <li><a href="#education">Education</a></li>
    <li><a href="#skills">Skills</a></li>
```

- Position: either within the header block (below contact row) or as a standalone minimal bar; NOT a separate fixed sidebar
- All section anchors use `scroll-behavior: smooth` (set on `<html>` in `index.css`)
- Nav links: Label size (14px), weight 400, ink color, no underline by default, underline on hover
- No hamburger menu required in Phase 1 shell (Phase 3 verifies full responsive behavior); nav collapses to `hidden` on mobile via `hidden md:flex` is acceptable for Phase 1

### App.js (shell composition)

**Section order (single-scroll):**
1. `<Header>` — identity + contacts
2. Summary prose
3. `<nav>` section anchors (if separate from header)
4. `<main>` — placeholder `<section>` elements with `id` anchors for: `#experience`, `#projects`, `#education`, `#skills`, `#leadership`
5. `<footer>` — minimal, no decorative elements

**Page-level classes on `<body>` or root div:** `bg-[#fafaf8] text-[#111] font-sans antialiased`

## Interaction Contracts

| Interaction | Behavior | Implementation |
|-------------|----------|----------------|
| Nav anchor click | Smooth scroll to section | `scroll-behavior: smooth` on `<html>` via `index.css` |
| Contact link hover | Underline appears | Tailwind `hover:underline` on `<a>` |
| Contact link focus | Visible focus ring | Tailwind `focus:outline-none focus:ring-2 focus:ring-[#111]` |
| External link (LinkedIn, GitHub) | Opens in new tab | `target="_blank" rel="noopener noreferrer"` |
| Email link | Opens mailto draft | `href="mailto:..."` — no JS handler |
| Nav link hover | Underline appears | Same as contact link hover |

**No animations in Phase 1.** Framer Motion is unused after FloatingSocialButtons deletion. No fade-in, no slide, no typewriter effect. Static render only.

**Reduced motion:** No animation to disable — this is already the reduced-motion state.

## Accessibility Baseline

| Requirement | Implementation |
|-------------|----------------|
| Heading hierarchy | `<h1>` for name, `<h2>` for each section heading in shell |
| Skip link | `<a href="#main" class="sr-only focus:not-sr-only">Skip to content</a>` as first child of `<body>` |
| Landmark regions | `<header>`, `<nav aria-label="Page sections">`, `<main>`, `<footer>` |
| Color contrast | #111 on #fafaf8 = 16.1:1 contrast ratio — exceeds WCAG AA (4.5:1) and AAA (7:1) |
| Link identification | All `<a>` elements have descriptive text labels; no icon-only links without `aria-label` |
| Focus visible | `focus:ring-2 focus:ring-[#111]` on all interactive elements |
| External links | `aria-label` includes "(opens in new tab)" for screen reader clarity |
